# Hangul Lesson 1: 한글 첫걸음 — Read Your First Korean Words

## Design Notes

**Start from the desired experience:** An absolute beginner who has *never seen Korean* sits down and, ~15 minutes later, reads a handful of real, warm words — 나, 너, 누나, 나무, 어머니 — and thinks *"Hangul is a system, and I can already read it."* Everything below protects that single feeling. We teach the fewest letters that still unlock real words, and we introduce **zero exceptions**.

**Medium is PDF, not an app.** There is no tapping, no clickable multiple-choice, no audio player. Every activity is something you can do with a pen or your voice: **read aloud** (the tutor confirms), **write / trace** the block, or **circle** a shape on the page. Activities are designed around that constraint, not retrofitted to it.

**No romanization.** We deliberately do NOT write na / neo / mo / eu under the Hangul. Transliteration becomes a crutch the student reads *instead of* the Korean, and the eo/eu/-style spellings are harder to parse than the letters themselves. Sound is conveyed two ways only: the **tutor reads each item aloud** (every page has a `▸` cue), and the letter-intro pages give a short **English anchor word** (e.g. ㅗ as in "go"). Once the letters are taught, the student decodes the Hangul directly.

**Why the old version was too much:** it taught 12 letters + the block rule + a 30-cell grid + listening discrimination + stroke-order writing in one sitting — and it smuggled in two *exceptions disguised as vocabulary*: ㅇ ("silent here… but actually 'ng' later") and ㅅ ("시 is read *shi*, not *si*"). A first-timer meets an exception before they can even read, panics, and the "this is easy" feeling is gone. Same mistake as cramming four conjugations into the pattern lesson — stealth concepts hiding as content.

**Two concepts ONLY:**

1. **The block idea** — a syllable is one square: a consonant (left or top) + a vowel. One block = one sound.
2. **A tiny, 100%-regular letter set** — 6 vowels (ㅏ ㅓ ㅗ ㅜ ㅡ ㅣ) + 2 perfectly regular consonants (**ㄴ** = n, **ㅁ** = m). Plus the silent **ㅇ**, taught only as "the empty seat" so a vowel never stands alone.

**The anchor / swap-one-slot move (borrowed from the pattern lesson):** fix the consonant, slide the vowels through it — 나 너 노 누 느 니 — then do the same with ㅁ. The consonant is the invariant; the vowel is the single moving part.

**Deliberately deferred (NOT this lesson):**
- ㄱ (g/k), ㅅ (시 softening), ㅎ, and all other consonants → later lessons.
- ㅇ as a final "ng" sound → much later.
- Batchim (bottom consonant) → only *teased* on the last page.

**Target words (built ONLY from ㅇ / ㄴ / ㅁ + the 6 vowels):**
나(I) · 너(you) · 아이(child) · 오이(cucumber) · 나무(tree) · 누나(older sister) · 이모(aunt) · 어머니(mother)

## Lesson Flow (11 Pages, ~18 min)

| Page | Activity                        | Time  | One idea per page                   |
| ---- | ------------------------------- | ----- | ----------------------------------- |
| 1    | Greeting & The Promise          | 2 min | "you'll read real Korean today"     |
| 2    | The One Idea: Blocks            | 2 min | consonant + vowel = one square      |
| 3    | The 6 Vowels (with silent ㅇ)    | 3 min | read aloud: 아 어 오 우 으 이         |
| 4    | Consonant ㄴ — slide the vowels  | 2 min | 나 너 노 누 느 니 (invariant + slot) |
| 5    | Consonant ㅁ — slide the vowels  | 2 min | 마 머 모 무 므 미                    |
| 6    | Read Your First Words           | 2 min | 나 · 너 · 나무 · 누나 · 어머니        |
| 7    | Quiz 1: Spot the Letter         | 1 min | recognition — circle the shape      |
| 8    | Quiz 2: Read Aloud              | 2 min | decoding — read blocks to the tutor |
| 9    | Quiz 3: Write the Block         | 2 min | recall — assemble / dictation       |
| 10   | Read the Sign (you can do this) | 1 min | read-aloud confidence payoff        |
| 11   | Wrap + Batchim Teaser           | 1 min | preview the next single load        |

**Core: ~18 min** (planning for 15–20 min actual class time)

**Quiz design — reading only, no meaning, pen + voice:** every quiz tests *decoding* (shape ↔ sound), never vocabulary, and every answer is given by **circling, writing, or reading aloud** — never tapping. All items use only the taught pieces (ㅇ ㄴ ㅁ + the 6 vowels).

### PAGE 1 — Greeting & The Promise

```text
+-------------------------------------------------------------------------+
|                                                                         |
|  한글 첫걸음                                                            |
|  Your First Steps in Hangul                                             |
|                                                                         |

|    「안녕하세요! 오늘 끝나면 한국어를 읽을 수 있어요. 약속해요!」          |

|                                                                         |
|                                                                  PAGE 1 |

```

### PAGE 2 — The One Idea: Blocks

```text
+-------------------------------------------------------------------------+
|                                                                         |
|  ▸ "One rule for the whole lesson: letters stack into a little square." |
|    「오늘의 규칙 하나: 글자를 네모 칸에 모아써요.」                       |
|                                                                         |
|  ONE BLOCK = ONE SOUND                                                  |
|  ──────────────────────                                                 |
|                                                                         |
|     ㄴ  +  ㅏ   →   나                                                   |
|                                                                         |
|     ┌───────┐                                                           |
|     │ ㄴ ㅏ │   consonant first, vowel after —                          |
|     │  =나  │   read the two pieces as ONE syllable.                    |
|     └───────┘                                                           |
|                                                                         |
|   ▸ "Listen as I say it, then say it with me."                          |
|     「제가 말하면 따라 해요.」                                            |
|                                                                         |
|   That's the whole trick. Everything today is just this, again         |
|   and again, with different pieces.                                     |
|                                                                         |
|                                                                  PAGE 2 |
+-------------------------------------------------------------------------+
```

### PAGE 3 — The 6 Vowels (with the silent seat ㅇ)

```text
+-------------------------------------------------------------------------+
|                                                                         |
|  ▸ "First the vowels. Copy my mouth — say each one with me."           |
|    「먼저 모음이에요. 제 입 모양을 따라 같이 소리 내요.」                 |
|                                                                         |
|  THE 6 VOWELS   (English word = the sound to copy)                     |
|  ────────────                                                           |
|     ㅏ   as in "father"        ㅜ   as in "moon"                        |
|     ㅓ   as in "son"           ㅡ   lips spread wide, flat (no round)   |
|     ㅗ   as in "go"            ㅣ   as in "see"                         |
|                                                                         |
|  - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - -   |
|                                                                         |
|   A vowel can't sit alone — it needs a seat. We use the SILENT ㅇ.      |
|   ㅇ at the front makes NO sound. It's just an empty chair:             |
|                                                                         |
|     ㅇ+ㅏ = 아     ㅇ+ㅓ = 어     ㅇ+ㅗ = 오                            |
|     ㅇ+ㅜ = 우     ㅇ+ㅡ = 으     ㅇ+ㅣ = 이                            |
|                                                                         |
|   ▸ "Read them out loud: 아 어 오 우 으 이. You just read Korean!"       |
|     「소리 내어 읽어요: 아 어 오 우 으 이. 벌써 읽었어요!」                |
|                                                                         |
|                                                                  PAGE 3 |
+-------------------------------------------------------------------------+
```

### PAGE 4 — Consonant ㄴ (slide the vowels)

```text
+-------------------------------------------------------------------------+
|                                                                         |
|  ▸ "Now ONE consonant: ㄴ sounds like 'n'. Keep it fixed; slide each    |
|     vowel in and read it with me."                                      |
|    「이제 자음 하나: ㄴ은 'n' 소리. ㄴ은 그대로, 모음만 바꿔요.」         |
|                                                                         |
|  ㄴ  ("n") — slide the 6 vowels through it                              |
|  ─────────────────────────────────────────                              |
|                                                                         |
|     ㄴ + ㅏ = 나          ㄴ + ㅜ = 누                                   |
|     ㄴ + ㅓ = 너          ㄴ + ㅡ = 느                                   |
|     ㄴ + ㅗ = 노          ㄴ + ㅣ = 니                                   |
|                                                                         |
|   ▸ "Read all six out loud. I'll go first, then you."                  |
|     「여섯 개를 소리 내어 읽어요. 제가 먼저, 그다음 ~씨.」                |
|                                                                         |
|        나   너   노   누   느   니                                      |
|                                                                         |
|   Notice: ㄴ never changed. Only the vowel moved. That's the rhythm.    |
|                                                                         |
|                                                                  PAGE 4 |
+-------------------------------------------------------------------------+
```

### PAGE 5 — Consonant ㅁ (slide the vowels)

```text
+-------------------------------------------------------------------------+
|                                                                         |
|  ▸ "Same move, new consonant: ㅁ sounds like 'm'. Fix it, slide the     |
|     vowels, read with me."                                              |

|                                                                         |
|  ㅁ  ("m") — slide the 6 vowels through it                              |
|  ─────────────────────────────────────────                              |
|                                                                         |
|     ㅁ + ㅏ = 마          ㅁ + ㅜ = 무                                   |
|     ㅁ + ㅓ = 머          ㅁ + ㅡ = 므                                   |
|     ㅁ + ㅗ = 모          ㅁ + ㅣ = 미                                   |
|                                                                         |
|   ▸ "You already know the rhythm. Read all six out loud."              |
|     「이미 리듬을 알아요. 여섯 개를 소리 내어 읽어요.」                   |
|                                                                         |
|        마   머   모   무   므   미                                      |
|                                                                         |
|   Two consonants. Six vowels. You can now read a LOT of words.          |
|                                                                         |
|                                                                  PAGE 5 |
+-------------------------------------------------------------------------+
```
