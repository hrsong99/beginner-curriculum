# 상황별 한국어 — 한 화의 페이지 구성

**이 문서는 목차가 아니라 지도다.** 어떤 페이지가 어떤 순서로 오는지, 각 페이지가 무엇을
하는 자리인지만 적는다. 실제 마크업과 말투는 여기서 베끼지 말고 **원본 덱**에서 가져온다.

- **원본 덱 (source of truth):** [`../../trial/lessons/trial-3-contextual-short.html`](../../trial/lessons/trial-3-contextual-short.html)
- **판매 페이지를 뺀 것:** [`sample-lesson.html`](./sample-lesson.html) — 새 화는 이 모양으로 나온다
- **이 화에 무엇을 담을지:** [`table-of-contents.md`](./table-of-contents.md)
- **컴포넌트 마크업:** [`../../AUTHORING.md`](../../AUTHORING.md)

이 지도로 페이지 계획을 세운 다음 **원본 덱을 통째로 읽는다.** 이 트랙은 특히 그렇다 —
파는 것이 문법이 아니라 장면이라, 대사가 드라마처럼 들리는지가 품질의 전부고 그건
지도로 옮겨지지 않는다.

---

## 이 트랙만 다른 점

**과가 아니라 화(話)다.** 이름 있는 작품이 있고 배역이 있고, 학습자는 구경꾼이 아니라
**배역을 맡는다.** 대사의 화자는 언제나 `나` 이고 상대 역은 튜터가 읽는다.

- **장면이 먼저 온다.** 핵심 트랙은 목표 → 패턴이지만 여기는 **장면 → 목표**다. 무슨 일이
  벌어지는지 보고 나서야 그 말을 왜 배우는지가 성립한다.
- **문법의 집은 여기가 아니다.** 진도가 아니라 재미가 목적이라 난이도가 들쭉날쭉해도 된다.
  학습자 진도보다 큰 번호의 형태가 나오면 통째로(`덩어리`) 익히고 넘어간다.
- **레벨이 중급 이상이면 가나 읽기(`.yomi`)를 달지 않는다.** 코스마다 다르므로
  `<meta name="podo:level">` 을 먼저 확인한다 — 케이팝 토크는 초급이라 달고,
  드라마 코스는 중급이라 달지 않는다.
- **한 화는 다음 화를 판다.** 원어민 팁까지 끝낸 뒤, **마지막 페이지**를 다음 화
  예고편으로 남긴다. 학습자가 수업을 닫을 때 마지막으로 보는 것은 다음 장면이다.

## 전체 골격

**장면 4장 + 패턴 파트 2개 + 되돌아오기 + 예고.** 보통 26–28장이다. 실제 형태 분기가
없는 패턴은 `pN-choose` 를 억지로 넣지 않으므로 정확한 장수보다 학습 가치가 우선이다.

| # | data-page-id | 자리 |
| ---: | --- | --- |
| 1 | `episode-card` | 작품·화수·배역. `.scene-cast` 로 누가 나오는지 |
| 2 | `scene` | **오늘의 장면.** 완성된 대사를 튜터와 함께 읽는다. 뜻은 아직 몰라도 된다 |
| 3 | `lesson-goal` | 「방금 그 장면, 끝나면 직접 말할 수 있어요」 — 장면과 목표를 잇는다 |
| 4 | `expressions` | 장면에 두 번 나온 표현 하나(`혹시` 같은). 패턴이 아니라 덩어리 |
| 5–13 | `part1-*` | 패턴 A — 아래 사다리 |
| 14–22 | `part2-*` | 패턴 B — 같은 사다리 |
| 23–26 | `part3-*` | 장면으로 되돌아온다 |
| 27 | `native-tip` | 원어민이 실제로 더 부드럽게 말하는 법 |
| 28 | `episode2-taste` | **마지막 페이지.** 다음 화 맛보기 |

**두 패턴은 반드시 그 장면 안에서 짝이어야 한다.** 패턴 B가 필요한 이유가 패턴 A를 썼기
때문이어야 한다 — 물어보고 답하기, 부탁하고 허락하기처럼. 문법 라벨이 같다는 것만으로는
짝이 아니다.

## 패턴 파트 (part1 · part2 공통)

핵심 트랙과 같은 사다리지만 **출발점이 장면의 대사**다. `p1-teach` 의 히어로 문장은
지어낸 예문이 아니라 2번 페이지에서 이미 들은 그 한 마디여야 한다.

| data-page-id | 컴포넌트 | 하는 일 | 모범 문장 |
| --- | --- | --- | :---: |
| `partN-intro` | `.transition-page` | 패턴 이름 한 줄 | — |
| `pN-teach` | `.sent-hero` | **장면에 있던 그 대사.** 튜터가 읽는다 | 있음 |
| `pN-read` | `.model-line` ×4 | 혼자 읽는다 | 있음 |
| `pN-rule` | `.batchim` / `.batchim.ending-rule` | 실제 형태 분기당 규칙 상자 하나 | — |
| `pN-choose` (조건부) | `.choose-row sentence` ×4 | 실제 두 형태를 구별할 때만 | 있음 |
| `pN-reorder` | `.task-block` ×4 + `.answer-box small` | 문장마다 의미 덩어리 4개 배열 | 없음 |
| `pN-fill` | `.task-block` ×4 + `.answer-box` | 빈칸은 패턴 자리만 | 없음 |
| `pN-translate` | `.task-block` ×4 + `.answer-box` | 일본어 → 한국어 | 없음 |
| `pN-write` | `.answer-box tall` | 자기 이야기 / 자기 질문 | 없음 |

`pN-rule` 의 상자 수는 예문 수가 아니라 **규칙의 갈래 수**다. `동사 어간 + 기 싫다`처럼
받침과 무관하게 한 방식이면 시각 상자도 하나만 둔다. `명사 + 만`과 `동사 + 기만 하다`처럼
만드는 방식이 둘이면 두 상자를 두고, 무엇이 갈라지는지 타일·제목·결과에서 바로 보이게 한다.

`pN-choose` 는 사다리의 고정 장수가 아니다. 두 선택지가 모두 문법적으로 가능하고 차이가
아직 배우지 않은 뉘앙스에 달렸거나, 한쪽이 그저 가짜 음절인 경우에는 페이지를 뺀다.
페이지 번호와 페이저는 `data-page-id` 로 움직이므로 중간 장을 생략해도 된다.

## 되돌아오기 (part3)

| data-page-id | 하는 일 |
| --- | --- |
| `part3-intro` | 「이제 당신 차례예요」 |
| `p3-model` | **2번의 그 장면을 다시.** 이번엔 뜻을 알고 읽는다 |
| `p3-complete` | 같은 장면, `나` 대사가 비어 있다 |
| `p3-freetalk` | 진짜 자기 이야기로 |

`p3-model` 이 같은 장면을 되풀이하는 것이 이 트랙의 설계다 — 처음엔 소리로 들었고,
이제 뜻을 쥐고 다시 연기한다. **새 장면으로 바꾸지 말 것.** 되돌아오는 것이 보상이다.

장면이 길어 스크롤이 생기는 것 자체는 문제가 아니다. 다만 고정 페이지 컨트롤 아래로
활동의 범위가 숨거나, 학습자가 대사가 얼마나 남았는지 알 수 없을 만큼 길어지면 장면을
나눈다. **문장 수가 아니라 극적 비트가 바뀌는 지점**(발견 → 확인, 부탁 → 대답, 갈등 →
반응)에서만 나누고, `scene-*` 과 `p3-model-*` 은 같은 비트 경계를 사용한다. 그래야 마지막
되돌아오기에서 처음 본 장면과 정확히 다시 만난다.

`episode2-taste` 는 일주일 뒤 같은 인물이다. 오늘 배운 패턴만 써서 빈칸을 채우게 한다 —
새 문법을 미리 꺼내는 자리가 아니라 다음 화를 궁금하게 만드는 자리다. 이 페이지 뒤에는
복습·팁·정리 페이지를 붙이지 않는다.

## 이 트랙에서 하지 않는다

- **문법 진도를 맞추려 하지 않는다.** 그 집은 `2-core-patterns` 다. 드라마 대사에서
  `~잖아`·`~더라`를 빼면 드라마가 아니게 된다.
- **학습자를 구경꾼으로 두지 않는다.** 대사의 화자는 언제나 `나` 다.
- **장면 없이 패턴부터 꺼내지 않는다.** 장면이 먼저다.
- **중급 이상 덱에 가나 읽기를 달지 않는다.**
