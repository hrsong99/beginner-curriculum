빈칸을 채워 주세요. 마지막은 한국어로 말해 볼까요?空欄をうめましょう。最後は韓国語で言ってみましょう。

です:이에요 / 예요

パート 1

~을/를 좋아해요

〜が好きです / 〜が好きじゃないです

패턴 1 (パターン 1)

같이 읽어 볼까요?一緒に読んでみましょう。

~을/를 좋아해요. 〜が好きです。
커피를 좋아해요. コーヒーが好きです。
~을/를 안 좋아해요. 〜が好きじゃないです。「안」は「좋아해요」の直前に置きます。
커피를 안 좋아해요. コーヒーは好きじゃないです。

을과 를, 어느 쪽? (을 と 를、どっち？)

단어의 끝을 봐 주세요.単語の終わりを見てください。

받침 パッチムあり（子音で終わる） → 을
밥을 책을 음악을
받침 없음 パッチムなし（母音で終わる） → 를
커피를 영화를 티비를

같이 읽어요 (一緒に読もう)

소리 내서 읽어 주세요.声に出して読んでください。

밥을 좋아해요.ご飯が好きです。
음악을 좋아해요.音楽が好きです。
빵을 안 좋아해요.パンは好きじゃないです。
티비를 안 좋아해요.テレビは好きじゃないです。

을과 를 고르기 (単語を仕分けよう)

을, 를 중에서 골라 주세요.「을」か「를」を選んでください。

밥 을/를
커피 을/를
책 을/를
영화 을/를

원어민 팁 (ネイティブのひとこと)

실제 대화에서는 이렇게 말하기도 해요.実際の会話では、こんなふうにも言います。

ネイティブのコツ

친한 사이의 편한 대화에서는 을/를을 자주 생략해요.

カジュアルな会話では「을/를」をよく省略します。

커피를 좋아해요? → 커피 좋아해요?（友達とのカフェで）
영화를 좋아해요? → 영화 좋아해요?

미션 완료 (ミッション完了)

할 수 있는 걸 체크해 주세요.できることをチェックしてください。

  • 을 と 를 を正しく選べる。
  • 好きなものを言える。
  • 好きじゃないものを言える。
  • 「〜が好きですか？」と聞ける。
  • 相手に何が好きか聞ける。
