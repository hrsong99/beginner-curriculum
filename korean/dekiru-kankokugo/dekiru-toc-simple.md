# Korean Curriculum

## LEVEL 1: 기초 한국어 (생존 표현과 기본 문장 만들기)

목표: 한국어의 기본 문장 뼈대를 세우고, 자기소개, 사물 확인, 위치 설명, 시간 말하기, 과거 경험, 부탁과 허가 표현까지 익히기.

---

## Unit 0: 시작하기

### 0. 수업과 인사 표현 익히기

1. 한국 지명 익히기: 서울, 부산, 제주도, 경기도, 강원도
2. 교실 표현 이해하기: 보세요, 쓰세요, 들으세요, 읽으세요
3. 대답하기: 네 / 아뇨 / 알겠어요 / 모르겠어요
4. 기본 인사하기: 안녕하세요, 오래간만입니다, 잘 지내셨어요?
5. 사과와 감사 표현하기: 죄송합니다, 괜찮아요, 감사합니다
6. 일상 정형 표현 익히기: 잘 먹겠습니다, 다녀오겠습니다, 안녕히 가세요 / 계세요

## Unit 1: 자기소개와 명사문 만들기

### 1. 저는 일본 사람입니다

1. “~입니다”로 말하기: `-입니다` (~입니다 / ~입니다)
2. 질문 만들기: `-입니까?` (~입니까?)
3. 주제 표시하기: `-은/는` (저는, 사람은, 회사는)
4. 이름 소개하기: `-(이)라고 합니다`
5. 국적과 직업 말하기: 일본 사람입니다, 회사원입니다, 학생입니다
6. 처음 만났을 때 말하기: 안녕하세요, 만나서 반갑습니다, 앞으로 잘 부탁합니다

### 2. 일본 사람이 아닙니다

1. “~이/가 아닙니다”로 부정하기: 일본 사람이 아닙니다
2. 주어 표시하기: `-이/가` (사람이, 제가)
3. 사람과 직업 확인하기: 저 사람이 요코즈나입니까?
4. 국적 묻기: 어느 나라 사람입니까?
5. 이름 묻고 답하기: 이름이 무엇입니까?
6. “그렇습니다 / 아닙니다”로 확인 답변하기

### 3. 그건 뭐예요?

1. 부드러운 “~예요/이에요” 쓰기: 책이에요, 사전이에요
2. 가까운 것 가리키기: `이것 / 이`
3. 그쪽·저쪽 것 가리키기: `그것 / 저것`, `그 / 저`
4. 무엇인지 묻기: 뭐예요? / 무엇입니까?
5. 소유자 확인하기: 누구 거예요?
6. 둘 중 하나 묻기: A예요? B예요?

### 4. 약속이 있습니다

1. 존재 말하기: `있습니다 / 있어요`
2. 부재 말하기: `없습니다 / 없어요`
3. 약속이나 수업이 있는지 묻기: 약속이 있습니까?
4. 장소에서 약속 말하기: 종로에서 친구하고 약속이 있습니다
5. 사람·사물의 있음/없음 구분하기
6. 오늘, 내일, 주말 일정 말하기

### 5. 회사는 어디에 있어요?

1. 위치 말하기: `-에 있어요`
2. 장소 묻기: 어디에 있어요?
3. 회사, 학교, 집 위치 설명하기
4. 가족 관계 말하기: 어머니, 아버지, 형, 언니, 동생
5. 위치어 쓰기: 앞, 뒤, 옆, 안, 밖, 위, 아래
6. “누가 어디에 있다” 문장 만들기

### Review 1: 제1과~제5과

1. 명사문 만들기: `-입니다`, `-예요/이에요`
2. 명사문 부정하기: `-이/가 아닙니다`
3. 기본 조사 복습하기: `-은/는`, `-이/가`, `-에`
4. 사물·사람·장소 묻고 답하기
5. 자기소개와 기본 위치 설명하기

## Unit 2: 동사 활용, 시간, 이동 말하기

### 6. 주말에는 뭐 합니까?

1. 격식체 동사 말하기: `-ㅂ/습니다`
2. 격식체 질문 만들기: `-ㅂ/습니까?`
3. 주말 활동 말하기: 공부합니다, 운동합니다, 쉽니다
4. 두 동작 연결하기: `-고` (~하고 ~합니다)
5. 기본 동사 익히기: 가다, 오다, 먹다, 마시다, 보다, 만나다
6. 주말에 무엇을 하는지 묻고 답하기

### 7. 그렇게 멀지 않습니다

1. 짧은 부정 만들기: `안 -` (안 가요, 안 먹어요)
2. 격식 부정 만들기: `-지 않습니다`
3. 시간 범위 말하기: `-부터 -까지`
4. 장소 범위 말하기: `-에서 -까지`
5. 거리와 교통수단 말하기: 멀다, 가깝다, 버스, 지하철
6. 하루 일정과 이동 시간 설명하기

### 8. 언제 갑니까?

1. 한자어 숫자 익히기: 일, 이, 삼, 사...
2. 날짜 말하기: 월, 일, 요일
3. “언제?”로 시간 묻기: 언제 갑니까?
4. 생일과 약속 날짜 말하기
5. 달력과 스케줄 읽기
6. 행사와 일정에 대해 묻고 답하기

### 9. 부산까지 어떻게 가요?

1. 해요체 현재형 만들기: `-아/어요`
2. 양성모음 활용하기: `-아요`
3. 음성모음 활용하기: `-어요`
4. 모음 축약 익히기: 가요, 봐요, 줘요, 마셔요
5. 방법 묻기: 어떻게 가요?
6. 목적지와 교통수단 말하기: 부산까지, 버스로, 지하철로

### 10. 몇 시부터예요?

1. 고유어 숫자 익히기: 하나, 둘, 셋...
2. 시간 말하기: 한 시, 두 시, 세 시 반
3. 시작 시간 묻기: 몇 시부터예요?
4. 끝나는 시간 말하기: 몇 시까지예요?
5. 수량과 단위 말하기: 명, 개, 잔, 병
6. 약속 시간과 영업시간 묻고 답하기

### Review 2: 제6과~제10과

1. 동사 현재형 복습하기: `-ㅂ/습니다`, `-아/어요`
2. 부정 표현 복습하기: `안 -`, `-지 않습니다`
3. 시간·날짜·숫자 말하기
4. 이동 방법과 교통수단 설명하기
5. 일상 활동과 스케줄 말하기

## Unit 3: 과거, 존댓말, 비교와 희망 표현

### 11. 언제 일본에 왔어요?

1. 과거 격식체 만들기: `-았/었습니다`
2. 과거 해요체 만들기: `-았/었어요`
3. 과거 모음 축약 익히기: 갔어요, 봤어요, 마셨어요
4. 언제 왔는지 묻기: 언제 일본에 왔어요?
5. 과거 경험 말하기: 어제 갔어요, 작년에 왔어요
6. 여행, 공부, 방문 경험 말하기

### 12. 성함이 어떻게 되세요?

1. 현재 존댓말 만들기: `-(으)십니다`, `-(으)세요`
2. 이름을 정중하게 묻기: 성함이 어떻게 되세요?
3. 특수 존댓말 익히기: 드시다, 계시다, 주무시다
4. 가족과 어른에 대해 정중하게 말하기
5. 높임 명사 익히기: 성함, 연세, 말씀
6. 개인 정보 공손하게 묻고 답하기

### 13. 어디에 다녀오셨어요?

1. 과거 존댓말 만들기: `-(으)셨습니다`, `-(으)셨어요`
2. 과거 존댓말 질문 만들기: `-(으)셨어요?`
3. 명사 존댓말 과거 쓰기: `-(이)셨어요?`
4. 휴가와 여행 경험 묻기
5. 어른의 과거 행동을 공손하게 말하기
6. 아직 안 했어요 / 벌써 했어요로 상태 답하기

### 14. 한국과 일본은 비슷하지만 많이 다르지요?

1. 확인 질문하기: `-지요? / -죠?`
2. “~죠?”로 동의 구하기: 맛있죠? 다르죠?
3. 역접 연결하기: `-지만`
4. 두 문화 비교하기: 비슷하지만 달라요
5. 습관과 문화 차이 설명하기
6. 음식, 교통, 생활방식 비교하기

### 15. 온천에 가고 싶어요

1. 희망 말하기: `-고 싶어요`
2. 희망 질문하기: 뭐 하고 싶어요?
3. 희망 부정하기: `-고 싶지 않아요`
4. 제3자의 희망 말하기: `-고 싶어 해요`
5. 여행 계획과 하고 싶은 일 말하기
6. 취미, 유학, 취직, 방학 계획 말하기

### Review 3: 제11과~제15과

1. 과거형 복습하기: `-았/었어요`
2. 존댓말 복습하기: `-(으)세요`, `-(으)셨어요`
3. 확인과 대조 표현 복습하기: `-지요?`, `-지만`
4. 희망 표현 복습하기: `-고 싶어요`
5. 경험, 여행, 문화 비교 말하기

## Unit 4: 이유, 허가, 제안, 부탁, 가능 표현

### 16. 선물을 사서 돈을 많이 써요

1. 이유 말하기: `-아/어서`
2. 원인과 결과 연결하기: 배가 고파서 밥을 먹었어요
3. 명사 이유 말하기: `-여서/-이어서`, `-라서/-이라서`
4. `으` 불규칙 활용하기: 바쁘다 → 바빠요, 쓰다 → 써요
5. 기념일과 선물 문화 말하기
6. 돈을 많이 쓰는 이유 설명하기

### 17. 결혼식에 뭘 입고 가면 돼요?

1. 허락 구하기: `-아/어도 돼요?`
2. 허락 답하기: 네, 해도 돼요 / 안 돼요
3. 금지 말하기: `-(으)면 안 돼요`
4. “어떻게 하면 돼요?” 묻기: `-(으)면 돼요?`
5. 조건 말하기: `-(으)면`
6. 결혼식, 규칙, 예절, 복장 이야기하기

### 18. 식사라도 같이 할까요?

1. 제안하기: `-(으)ㄹ까요?`
2. 같이 하자고 말하기: `-(으)ㅂ시다`
3. 목적 말하기: `-(으)러`
4. 선택지 제안하기: 부산에 갈까요? 제주도에 갈까요?
5. 약속 장소와 시간 정하기
6. 식사, 차, 만남, 외출 계획 세우기

### 19. 사진 좀 찍어 주시겠어요?

1. 정중하게 부탁하기: `-아/어 주시겠어요?`
2. 직접 부탁하기: `-아/어 주세요`
3. 더 격식 있게 부탁하기: `-아/어 주십시오`
4. 부탁 앞에 완충 표현 넣기: `-ㅂ/습니다만`
5. 사진, 택시, 식당, 전화 상황에서 부탁하기
6. 죄송합니다만 / 미안합니다만으로 부드럽게 말하기

### 20. 자전거를 탈 수 있어요?

1. 가능 말하기: `-(으)ㄹ 수 있어요`
2. 가능 질문하기: 탈 수 있어요? 할 수 있어요?
3. 불가능 말하기: `못-`, `-(으)ㄹ 수 없어요`
4. 현재 진행 말하기: `-고 있어요`
5. 능력과 가능성을 구분해서 말하기
6. 시설 이용 가능 여부와 금지 사항 묻기

### Review 4: 제16과~제20과

1. 이유와 원인 말하기: `-아/어서`
2. 허가와 금지 말하기: `-아/어도 돼요`, `-(으)면 안 돼요`
3. 제안과 목적 말하기: `-(으)ㄹ까요?`, `-(으)ㅂ시다`, `-(으)러`
4. 부탁하기: `-아/어 주시겠어요?`, `-아/어 주세요`
5. 가능·불가능·진행 말하기: `-(으)ㄹ 수 있어요`, `못-`, `-고 있어요`
