好きなものを言おう

今日のパターンは2つ。自分の好きなものを言って、相手の好きなものを聞いてみましょう。

今日のパターン ~을/를 좋아해요
~을/를 좋아해요? 〜が好きです / 〜が好きですか？

あいさつ

잘 듣고, 인사해 보세요.よく聞いて、あいさつを返してみましょう。

前回のおさらい

빈칸을 채우고, 마지막 문장은 한국어로 말해 보세요.空欄をうめて、最後の文は韓国語で言ってみましょう。

パート 1

~을/를 좋아해요

〜が好きです / 〜が好きじゃないです

パターン 1

패턴과 예문을 같이 읽어 보세요.パターンと例文を一緒に読んでみましょう。

~을/를 좋아해요. 〜が好きです。
커피를 좋아해요. コーヒーが好きです。
~을/를 안 좋아해요. 〜が好きじゃないです。「안」は「좋아해요」の直前に置きます。
커피를 안 좋아해요. コーヒーは好きじゃないです。

을 と 를、どっち？

단어의 마지막 소리를 보세요.単語の最後の音に注目しましょう。

받침 パッチムあり（子音で終わる） → 을 밥을 책을 음악을
받침 없음 パッチムなし（母音で終わる） → 를 커피를 영화를 티비를

一緒に読もう

문장을 소리 내어 읽어 보세요.文を声に出して読んでみましょう。

밥을 좋아해요.ご飯が好きです。
음악을 좋아해요.音楽が好きです。
빵을 안 좋아해요.パンは好きじゃないです。
티비를 안 좋아해요.テレビは好きじゃないです。

単語を仕分けよう

단어를 알맞은 칸에 넣고, 좋아해요와 같이 말해 보세요.単語を正しい枠に入れて、좋아해요 と一緒に言ってみましょう。

밥 커피 물 영화 책 음악
~을
パッチムあり（子音で終わる）
~를
パッチムなし（母音で終わる）

을 か 를 を選ぼう

빈칸에 알맞은 조사를 써 보세요.空欄に正しい助詞を書きましょう。

本が好きです。 책 좋아해요.
コーヒーは好きじゃないです。 커피 안 좋아해요.
水が好きです。 물 좋아해요.

韓国語にしよう

먼저 말하고, 그다음에 써 보세요.まず言ってから、書いてみましょう。

映画が好きです。
映画:영화
ご飯は好きじゃないです。
ご飯:밥
パート 2

~을/를 좋아해요?

〜が好きですか？ / 何が好きですか？

パターン 2

질문은 같은 문장이에요. 끝만 올려 보세요.疑問文は同じ文です。文末を上げるだけ。

~을/를 좋아해요? 〜が好きですか？
빵을 좋아해요? パンは好きですか？
뭘 좋아해요? 何が好きですか？
뭘 좋아해요? — 커피를 좋아해요. 何が好きですか？ — コーヒーが好きです。
좋아해요. 平叙文 ↘ 下げる
좋아해요? 疑問文 ↗ 上げる

質問を読もう

끝을 올리면서 질문을 읽어 보세요.文末を上げながら、質問を読んでみましょう。

책을 좋아해요?本は好きですか？
영화를 좋아해요?映画は好きですか？
뭘 좋아해요?何が好きですか？
뭘 안 좋아해요?何が好きじゃないですか？

質問にしてみよう

문장을 읽고, 질문으로 바꿔서 물어보세요.文を読んで、質問に変えて聞いてみましょう。

밥을 좋아해요. → ?「ご飯は好きですか？」と聞いてみよう
커피를 좋아해요. → ?「コーヒーは好きですか？」と聞いてみよう
음악을 좋아해요. → ?「音楽は好きですか？」と聞いてみよう

質問を完成させよう

빈칸에 알맞은 말을 써 보세요.空欄に合う言葉を書きましょう。

コーヒーは好きですか？ 커피를 좋아해?
音楽は好きですか？ 음악 좋아해요?
映画は好きですか？ 영화 좋아해요?

韓国語にしよう

먼저 말하고, 그다음에 써 보세요.まず言ってから、書いてみましょう。

パンは好きですか？
パン:빵
何が好きですか？
何を:뭘

正しい言葉を選ぼう

알맞은 말을 골라서 문장을 말해 보세요.正しい言葉を選んで、文を言ってみましょう。

저는 책을 ( 안 / 뭘 ) 좋아해요. 영화 ( 을 / 를 ) 좋아해요? ( 뭘 / 물 ) 좋아해요? — 커피를 좋아해요.

文を組み立てよう

단어를 순서대로 놓고, 문장을 말해 보세요.単語を正しい順番に並べて、文を言ってみましょう。

パンが好きです。
저는 빵을 좋아해요
テレビは好きじゃないです。
티비를 안 좋아해요
