初級パターンレッスン

좋아하는 것을 말해요 (好きなものを言おう)

今日のパターンは2つ。自分の好きなものを言って、相手の好きなものを聞いてみましょう。

今日のパターン ~을/를 좋아해요
~을/를 좋아해요? 〜が好きです / 〜が好きですか？

복습 (前回のおさらい)

빈칸을 채우고, 마지막 문장은 한국어로 말해 보세요.空欄をうめて、最後の文は韓国語で言ってみましょう。

~이에요 / ~예요 〜です
これは本です。 이거는 책이에요.
私は学生です。 저는 학생이에요.
あれはコーヒーです。 저거는 커피예요
あれ:저거 コーヒー:커피
パート 1

~을/를 좋아해요

〜が好きです / 〜が好きじゃないです

패턴 1 (パターン 1)

패턴과 예문을 같이 읽어 보세요.パターンと例文を一緒に読んでみましょう。

~을/를 좋아해요. 〜が好きです。
커피를 좋아해요. コーヒーが好きです。
~을/를 안 좋아해요. 〜が好きじゃないです。「안」は「좋아해요」の直前に置きます。
커피를 안 좋아해요. コーヒーは好きじゃないです。

을과 를, 어느 쪽? (을 と 를、どっち？)

단어의 마지막 소리를 보세요.単語の最後の音に注目しましょう。

받침 パッチムあり（子音で終わる） → 을
밥을 책을 음악을
받침 없음 パッチムなし（母音で終わる） → 를
커피를 영화를 티비를

같이 읽어요 (一緒に読もう)

문장을 소리 내어 읽어 보세요.文を声に出して読んでみましょう。

밥을 좋아해요.ご飯が好きです。
음악을 좋아해요.音楽が好きです。
빵을 안 좋아해요.パンは好きじゃないです。
티비를 안 좋아해요.テレビは好きじゃないです。

을과 를 고르기 (単語を仕分けよう)

각 단어에 알맞은 조사를 골라 보세요.それぞれの単語に合う助詞を選びましょう。

밥 을/를
커피 을/를
책 을/를
영화 을/를

문장 만들기 (文を組み立てよう)

단어를 순서대로 놓고, 문장을 말해 보세요.単語を正しい順番に並べて、文を言ってみましょう。

パンが好きです。 저는 빵을 좋아해요
빵을 좋아해요 저는
テレビは好きじゃないです。 티비를 안 좋아해요
좋아해요 티비를 안
コーヒーが好きです。 저는 커피를 좋아해요
커피를 저는 좋아해요
音楽は好きじゃないです。 음악을 안 좋아해요
안 음악을 좋아해요

빈칸을 채워요 (空欄をうめよう)

빈칸에 알맞은 말을 써 보세요.空欄に合う言葉を書きましょう。

本が好きです。 책 을 좋아해요.
コーヒーは好きじゃないです。 커피 를 안 좋아해요.
水が好きです。 물 을 좋아해요.
パンは好きじゃないです。 빵을 안 좋아해요.

한국어로 바꿔요 (韓国語にしよう)

문장을 한국어로 번역해 보세요.文を韓国語に翻訳しましょう。

映画が好きです。 영화를 좋아해요
映画:영화
ご飯は好きじゃないです。 밥을 안 좋아해요
ご飯:밥
コーヒーが好きです。 커피를 좋아해요
コーヒー:커피
水は好きじゃないです。 물을 안 좋아해요
水:물

스스로 문장 쓰기 (自分で文を作ろう)

아무 도움 없이, 좋아하는 것을 한 문장으로 써 보세요.ヒントなしで、好きなものを一つの文で書いてみましょう。

パート 2

~을/를 좋아해요?

〜が好きですか？ / 何が好きですか？

패턴 2 (パターン 2)

질문은 같은 문장이에요. 끝만 올려 보세요.疑問文は同じ文です。文末を上げるだけ。

~을/를 좋아해요? 〜が好きですか？
빵을 좋아해요? パンは好きですか？
뭘 좋아해요? 何が好きですか？
뭘 좋아해요? — 커피를 좋아해요. 何が好きですか？ — コーヒーが好きです。
좋아해요. 平叙文 ↘ 下げる
좋아해요? 疑問文 ↗ 上げる

질문을 읽어요 (質問を読もう)

끝을 올리면서 질문을 읽어 보세요.文末を上げながら、質問を読んでみましょう。

책을 좋아해요?本は好きですか？
영화를 좋아해요?映画は好きですか？
뭘 좋아해요?何が好きですか？
뭘 안 좋아해요?何が好きじゃないですか？

질문으로 바꿔요 (質問にしてみよう)

문장을 읽고, 질문으로 바꿔서 물어보세요.文を読んで、質問に変えて聞いてみましょう。

밥을 좋아해요. → 밥을 좋아해요?「ご飯は好きですか？」と聞いてみよう
커피를 좋아해요. → 커피를 좋아해요?「コーヒーは好きですか？」と聞いてみよう
음악을 좋아해요. → 음악을 좋아해요?「音楽は好きですか？」と聞いてみよう
영화를 좋아해요. → 영화를 좋아해요?「映画は好きですか？」と聞いてみよう

알맞은 말 고르기 (正しい言葉を選ぼう)

알맞은 말을 골라서 문장을 말해 보세요.正しい言葉を選んで、文を言ってみましょう。

私は本が好きじゃないです。 저는 책을 안/뭘 좋아해요.
映画は好きですか？ 영화 을/를 좋아해요?
何が好きですか？ — コーヒーが好きです。 뭘/물 좋아해요? — 커피를 좋아해요.
パンは好きですか？ 빵 을/를 좋아해요?

문장 만들기 (文を組み立てよう)

단어를 순서대로 놓고, 질문을 말해 보세요.単語を正しい順番に並べて、質問を言ってみましょう。

パンは好きですか？ 빵을 좋아해요?
좋아해요? 빵을
映画は好きですか？ 영화를 좋아해요?
영화를 좋아해요?
何が好きですか？ 뭘 좋아해요?
좋아해요? 뭘
テレビは好きじゃないですか？ 티비를 안 좋아해요?
안 좋아해요? 티비를

질문을 완성해요 (質問を完成させよう)

빈칸에 알맞은 말을 써 보세요.空欄に合う言葉を書きましょう。

映画は好きですか？ 영화 를 좋아해요?

한국어로 바꿔요 (韓国語にしよう)

원어민 팁 (ネイティブのひとこと)

실제 대화에서는 이렇게 말하기도 해요.実際の会話では、こんなふうにも言います。

ネイティブのコツ

친한 사이의 편한 대화에서는 을/를을 자주 생략해요.

カジュアルな会話では「을/를」をよく省略します。

커피를 좋아해요? → 커피 좋아해요?（友達とのカフェで）
영화를 좋아해요? → 영화 좋아해요?

미션 완료 (ミッション完了)

할 수 있는 것을 체크해 보세요.できるようになったことをチェックしましょう。

  • 을 と 를 を正しく選べる。
  • 好きなものを言える。
  • 好きじゃないものを言える。
  • 「〜が好きですか？」と聞ける。
  • 相手に何が好きか聞ける。
