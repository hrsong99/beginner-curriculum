# English Freetalking — Topics

**10 themes · 50 topics × 2 levels · growing.** One topic = one session.

**This track has no finish line.** Every other track ends; this one gains topics every week. Each
topic is self-contained — an opening question, two moves to borrow, a question ladder, and enough
to fill 25 minutes without the tutor improvising.

**No new grammar.** Every session takes two conversation moves the learner already owns from Core or
Contextual, or makes one transparent discourse-level extension of them, and uses that pair
repeatedly around one interesting question.

*Rebuilt 2026-08-13. All Core references derived against the current 122-lesson spine.*

---

## The failure mode is not a boring topic — it is a topic with no answer

> **"What does success mean to you?"** reads well in a table of contents. Ask it and an adult cannot
> produce a first sentence within three seconds **in their own language**, let alone in English.
> **"What's the best thing you've bought this year?"** looks shallow, but the answer arrives
> instantly, and the answer is a *story* — which is what keeps a 25-minute session moving.

This track picks the second kind, every time. The previous version of this file opened with *What
does success mean to you?*, and also carried *What makes a job meaningful?* and *Is convenience worth
the environmental cost?* — three essay prompts wearing conversation clothes. They are gone.

**The selection rules:**

1. **Three seconds.** If the learner cannot begin answering in their L1 within three seconds, the
   topic is an essay prompt. Depth comes from the *answer*, never from the question. Titles shaped
   like "What is ___?" or "Is ___ worth it?" almost always fail this.
2. **Experience over opinion.** Abstract opinion topics carry a vocabulary tax — to discuss work-life
   balance you need abstract nouns a B2 learner may not have, so the session stalls on lexis rather
   than ideas. Experience topics run on verbs the learner already owns, which is why fluency actually
   grows.
3. **The answer must contain a story, not a position.** A position is one sentence and then silence.
   A story has a when, a who, and a what-happened-next, and every one of those is a follow-up.
4. **It has to be answerable by someone whose life is ordinary.** Topics that assume travel, money or
   an interesting job exclude most of the class.

Opinion is not banned — it is *arrived at*. Several topics below end by asking for a position, but
only after the learner has spent fifteen minutes on the experience that earns it.

## Two versions of every topic

Same theme, same question, same session shape. Only the **language load** differs.

| Version | How it is made |
| --- | --- |
| **B2–C1 · full** | Written **first**, with no constraints — the most natural and interesting way to run this topic. |
| **B1 · accessible** | Derived from it. Simplify the opening passage first; then change **only** the questions that genuinely block an answer. |

**The accessible version is not an abridgement.** It keeps the same facts, the same positions and the
same depth of thinking — otherwise the later questions lose the anchor they refer back to. What
changes is vocabulary, clause length, and how many things one question asks at once. A question that
is already natural and answerable stays exactly as it is.

Priority when simplifying: (1) the opening passage — short sentences, frequent words, one piece of
information each; (2) the on-screen questions — keep the meaning and the job, lower the vocabulary;
(3) the tutor's follow-up questions — only the ones that block.

## The session shape

Hook → quick position → **Move A** → follow-up ladder → **Move B** → changed or strengthened position.

Every topic below carries its **own** ladder. The previous version of this file had one generic
six-rung ladder shared by all 24 topics, which meant the tutor improvised the actual conversation
every time — the ladder is where the session's value lives, so it is written per topic.

**Entry floor: Core 53.** Below that the learner does not yet have the past, the perfect and the
connectors a story needs, and the session becomes a vocabulary lesson. Individual topics name a
higher floor where they need one.

# Theme 1 · Lately

*The highest three-second compliance in the track. Nothing here needs recall or opinion — it happened
this week.*

**1. What's the best thing you've bought this year?**

*3秒: everyone has bought something, and the good ones come with a story about deciding.*
- Move A: "The best thing I've bought is..." — `The best thing I've ___ is ___.` **(Core 49)**
- Move B: "I use it almost every day." — `I use it ___.` **(Core 12, 17)**
- *Ladder:* What is it? → When did you buy it? → What made you decide? → Was it expensive — did that
  matter? → What's something you regret buying? → Would you buy it again?
- *B1 / B2+:* B1 keeps it concrete (an object). B2+ allows "thing" to include an experience, a
  subscription, a course — which opens the value question underneath it.

**2. What did you do last weekend — honestly?**

*3秒: it was two days ago. The word "honestly" gives permission for the answer to be "nothing".*
- Move A: "I didn't do much, really." — `I didn't ___, really.` **(Core 34)**
- Move B: "I spent most of it..." — `I spent most of it ___ing.` **(Core 52)**
- *Ladder:* What did you actually do? → Was that the plan? → What did you mean to do? → Do you prefer
  a full weekend or an empty one? → When was the last really good one? → What made it good?
- *B1 / B2+:* identical questions. Only the model answer's length differs. This topic needs no
  simplification, which is the point of the "change only what blocks" rule.

**3. What's something small that made your week better?**

*3秒: deliberately small, so nobody has to have had a good week.*
- Move A: "It sounds silly, but..." — `It sounds ___, but ___.` **(Core 56)**
- Move B: "It made a bigger difference than I expected." — `It ___ more than I expected.` **(Core 45)**
- *Ladder:* What was it? → When? → Why did that matter to you? → Do small things usually help, or do
  you need a big one? → What ruins a week? → What would you do differently?
- *B1 / B2+:* B2+ adds "does that say something about you?" as a closing rung.

**4. What have you been putting off?**

*3秒: everyone has one, and admitting it is easier than defending an opinion.*
- Move A: "I've been meaning to..." — `I've been meaning to ___.` **(Core 52)**
- Move B: "I keep not doing it because..." — `I keep ___ing because ___.` **(Core 54)**
- *Ladder:* What is it? → How long? → What's actually stopping you? → What happens if you never do
  it? → What did you put off before and finally do? → How did that feel?
- *B1 / B2+:* B1 uses "I want to do it, but..." instead of "I've been meaning to".

**5. What's the last thing that made you laugh?**

*3秒: recall is easy and retelling is naturally animated.*
- Move A: "It was one of those things where..." — `It was one of those ___ where ___.` **(Core 55)**
- Move B: "You had to be there." — `You had to ___.` **(Core 41)**
- *Ladder:* What happened? → Who were you with? → Why was it funny? → Does that kind of thing usually
  make you laugh? → What doesn't work on you? → Who's the funniest person you know?
- *B1 / B2+:* B1 drops "one of those things where" and uses "Something funny happened. I was...".

# Theme 2 · Things you own

*Objects are the safest possible entry to storytelling — concrete, visible, and everyone has them.*

**6. What's the oldest thing you own?**

*3秒: an object, and its age is a fact, not a judgement.*
- Move A: "I've had it since..." — `I've had it since ___.` **(Core 51)**
- Move B: "I keep it because..." — `I keep it because ___.` **(Core 54)**
- *Ladder:* What is it? → How did you get it? → Why have you kept it? → Do you keep things or throw
  them away? → What have you thrown away and regretted? → What will you never get rid of?
- *B1 / B2+:* B2+ can push into "what does keeping things say about a person?" — abstraction earned
  by fifteen minutes of concrete detail first.

**7. What's in your bag right now?**

*3秒: it is physically present. Zero recall cost.*
- Move A: "I always carry..." — `I always carry ___.` **(Core 12)**
- Move B: "I don't know why I still have this." — `I don't know why ___.` **(Core 62)**
- *Ladder:* What's in there? → What do you actually use? → What's been in there for months? → What do
  you always forget? → Has your bag changed in the last few years? → What does it say about your day?
- *B1 / B2+:* same questions throughout; B1's model answer lists, B2+'s narrates.

**8. What's something you bought and never used?**

*3秒: the mild embarrassment makes it easy to say and fun to hear.*
- Move A: "I was going to use it, but..." — `I was going to ___, but ___.` **(Core 74)**
- Move B: "It's still in the box." — `It's still ___.` **(Core 49)**
- *Ladder:* What was it? → What did you imagine doing with it? → What actually happened? → Do you do
  this often? → What stops you? → What would make you actually use it?
- *Floor: Core 74.*

**9. If your place caught fire, what would you take?**

*3秒: hypothetical, but the answer is a concrete object — which is why this one works where most
hypotheticals don't.*
- Move A: "I'd probably grab..." — `I'd probably ___.` **(Core 66)**
- Move B: "Everything else can be replaced." — `___ can be replaced.` **(Core 65)**
- *Ladder:* What would you take? → Why that? → What surprised you about your own answer? → What
  wouldn't you take that other people would? → Has anything ever been lost or broken? → What did you
  learn?
- *Floor: Core 66.*

**10. What do you spend money on that other people think is a waste?**

*3秒: a defence, and people defend readily.*
- Move A: "People think it's a waste, but..." — `People think ___, but ___.` **(Core 56)**
- Move B: "For me it's worth it because..." — `For me it's worth it because ___.` **(Core 54)**
- *Ladder:* What is it? → How much, roughly? → Who thinks it's a waste? → What's their argument? →
  Is there anything you think *is* a waste? → Have you ever changed your mind about one?
- *B1 / B2+:* B2+ adds "is there a line for you?" — the first genuine value question in the theme.

# Theme 3 · Food

*Universally available, no cultural or financial prerequisite, and Japanese learners have unusually
strong opinions here — which is an asset.*

**11. What did you eat yesterday?**

*3秒: it was yesterday.*
- Move A: "For lunch I had..." — `For ___ I had ___.` **(Core 32)**
- Move B: "It's what I usually have." — `It's what I usually ___.` **(Core 12)**
- *Ladder:* What did you eat? → Is that typical? → Who cooked? → Do you eat the same things every
  week? → When do you eat something different? → What did you eat as a child that you don't now?

**12. What's a food you couldn't live without?**

*3秒: instant, and strongly felt.*
- Move A: "I could eat it every day." — `I could ___ every day.` **(Core 66)** `chunk`
- Move B: "I never get tired of it." — `I never get tired of ___.` **(Core 14)**
- *Ladder:* What is it? → How often, honestly? → Is it about taste or habit? → What's a food you used
  to love and stopped? → What happened? → Is there anything you'd miss abroad?

**13. What's the best meal you've had in the last year?**

*3秒: "in the last year" bounds the search so nobody freezes trying to pick the best ever.*
- Move A: "It wasn't fancy, but..." — `It wasn't ___, but ___.` **(Core 56)**
- Move B: "What made it good was the..." — `What made it good was ___.` **(Core 103)** `chunk`
- *Ladder:* Where? Who with? → What did you have? → What made it good — the food or something else? →
  Have you been back? → Is a meal ever just about the food? → Where are you going next?

**14. Is there a food you pretend to like?**

*3秒: a small confession, and confession is fast.*
- Move A: "I don't really like it, to be honest." — `I don't really ___, to be honest.` **(Core 14)**
- Move B: "I eat it because everyone else does." — `I ___ because everyone else ___.` **(Core 54)**
- *Ladder:* What is it? → Where do you have to eat it? → Has anyone noticed? → Why not just say so? →
  Is there something everyone loves that you don't get? → Would you say so at a dinner?
- *B1 / B2+:* B2+ closes on the politeness question — when is honesty rude? That is the abstraction,
  and it comes last.

**15. What can you actually cook?**

*3秒: a capability question with a factual answer.*
- Move A: "I can make about three things." — `I can ___ about ___.` **(Core 20)**
- Move B: "I learned it from..." — `I learned it from ___.` **(Core 32)**
- *Ladder:* What can you make? → Who taught you? → When do you cook? → What went wrong the last time?
  → Do you want to cook more, or not really? → What would you learn if you had a month?

# Theme 4 · Places

*Not "travel" — that excludes anyone who hasn't. Places includes the station near your house.*

**16. Where do you go when you want to be alone?**

*3秒: everyone has a place, and describing it is easy.*
- Move A: "There's a place near my house..." — `There's a ___ near ___.` **(Core 7)**
- Move B: "I go there when I need to..." — `I go there when I ___.` **(Core 58)**
- *Ladder:* Where is it? → What's it like? → When did you find it? → How often? → What do you do
  there? → Does anyone else know about it?

**17. What's a place you keep going back to?**

*3秒: repetition means memory is easy.*
- Move A: "I've been there so many times." — `I've been ___ so many times.` **(Core 48)**
- Move B: "It hasn't changed at all." — `It hasn't ___ at all.` **(Core 49)**
- *Ladder:* Where? → When did you first go? → What keeps you going back? → Has it changed? → Has your
  reason changed? → Is there somewhere you used to go and stopped?

**18. What's the last place that surprised you?**

*3秒: surprise is memorable by definition.*
- Move A: "I expected it to be..., but..." — `I expected it to be ___, but ___.` **(Core 56)**
- Move B: "It wasn't what I imagined at all." — `It wasn't ___ at all.` **(Core 44)**
- *Ladder:* Where? → What did you expect? → What was it actually like? → Where did the expectation
  come from? → Has that happened the other way — somewhere disappointing? → Does it change how you
  plan?

**19. Where would you live for a year if money didn't matter?**

*3秒: hypothetical, but the answer is a place name — immediate.*
- Move A: "If I could live anywhere, I'd choose..." — `If I could ___, I'd ___.` **(Core 66)**
- Move B: "The main reason is..." — `The main reason is ___.` **(Core 103)** `chunk`
- *Ladder:* Where? → Why there? → What would you actually do all day? → What would you miss? → Could
  you do it for five years, or just one? → What's stopping you doing a month of it now?
- *Floor: Core 66.*

**20. What's somewhere in Japan you've never been but should have?**

*3秒: the gap is easy to name, and mild guilt makes it fun.*
- Move A: "I've never actually been." — `I've never actually ___.` **(Core 48)**
- Move B: "I keep meaning to go." — `I keep meaning to ___.` **(Core 52)**
- *Ladder:* Where? → Why haven't you? → Who has been? What did they say? → What would you do there? →
  Is there somewhere foreigners always ask about that you don't know? → When could you actually go?

# Theme 5 · People

*Other people are easier to talk about than yourself, which makes this theme a good early one.*

**21. Who do you talk to most?**

*3秒: a factual answer about a real person.*
- Move A: "Probably my..." — `Probably my ___.` **(Core 4)**
- Move B: "We talk about nothing, mostly." — `We ___ about ___, mostly.` **(Core 12)**
- *Ladder:* Who? → How often? → What do you actually talk about? → Has that changed? → Who did you
  talk to most five years ago? → What happened?

**22. Who's the most interesting person you know?**

*3秒: people volunteer this one immediately.*
- Move A: "He's the kind of person who..." — `___ is the kind of person who ___.` **(Core 55)**
- Move B: "What I like about him is..." — `What I like about ___ is ___.` **(Core 103)** `chunk`
- *Ladder:* Who? → How do you know them? → What makes them interesting? → Are you like them? →
  Who else would say the same about them? → Is interesting the same as likeable?

**23. Who taught you something that stuck?**

*3秒: specific, and gratitude is easy to voice.*
- Move A: "Someone once told me to..." — `Someone once told me to ___.` **(Core 70)** `chunk`
- Move B: "It helped because..." — `It helped because ___.` **(Core 54)**
- *Ladder:* Who? → What did they say? → When? → Did you understand it then? → Have you passed it on? →
  What advice have you ignored?

**24. Who do you disagree with and still like?**

*3秒: specific person, and the tension is interesting.*
- Move A: "We don't agree about..." — `We don't agree about ___.` **(Core 14)**
- Move B: "It doesn't get in the way." — `It doesn't ___.` **(Core 14)**
- *Ladder:* Who, and about what? → How did it come up? → Do you argue or avoid it? → Has either of you
  moved? → Is there anything you couldn't get past? → Should friends agree about the big things?
- *B1 / B2+:* B2+ closes on the last rung as a genuine position question. B1 stops at the fifth.
- *Floor: Core 92.*

**25. Who would you call at 3 a.m.?**

*3秒: one name, arrives instantly, and it means something.*
- Move A: "There's really only one person." — `There's really only ___.` **(Core 106)** `chunk`
- Move B: "I've never had to, but I know I could." — `I've never had to, but ___.` **(Core 48)**
- *Ladder:* Who? → Why them? → Have you ever actually needed to? → Who would call *you*? → Has the
  answer changed over time? → Does distance matter?

# Theme 6 · Work and money

*Concrete and universal for adult learners. Kept factual — "what is a meaningful job" is exactly the
essay prompt this track exists to avoid.*

**26. What does your day actually look like?**

*3秒: it happened today.*
- Move A: "Most of my day is..." — `Most of my day is ___ing.` **(Core 52)**
- Move B: "The part people don't see is..." — `The part people don't see is ___.` **(Core 103)** `chunk`
- *Ladder:* Walk me through it → Which part takes longest? → Which part do you like? → What would
  surprise someone outside your job? → Has it changed since you started? → What would you cut?

**27. What was your first job?**

*3秒: memory, and first jobs are almost always a story.*
- Move A: "My first job was..." — `My first job was ___.` **(Core 30)**
- Move B: "I lasted about..." — `I lasted about ___.` **(Core 51)**
- *Ladder:* What was it? → How old were you? → What did you actually do? → What was the worst part? →
  What did you learn that you still use? → Would you do it now?

**28. What's the best or worst boss you've had?**

*3秒: everyone has one, and the stories arrive fully formed.*
- Move A: "She was the kind of manager who..." — `___ was the kind of ___ who ___.` **(Core 55)**
- Move B: "What made the difference was..." — `What made the difference was ___.` **(Core 103)** `chunk`
- *Ladder:* Who, and which? → One specific thing they did → How did the team react? → Did you say
  anything? → What did you take from it? → What kind of manager would you be?

**29. What would you do with a year off and enough money?**

*3秒: hypothetical, but people have this answer ready.*
- Move A: "The first thing I'd do is..." — `The first thing I'd do is ___.` **(Core 66)**
- Move B: "After a month I'd probably get bored of it." — `After ___ I'd probably ___.` **(Core 66)**
- *Ladder:* First month? → Then what? → Would you tell people you weren't working? → What would you
  miss? → Do you know anyone who's done it? → Would you actually take it if offered?
- *Floor: Core 66.*

**30. What's something at work you'd change if you could?**

*3秒: everyone has one and it is specific.*
- Move A: "If it were up to me, I'd..." — `If it were up to me, I'd ___.` **(Core 66)**
- Move B: "The problem is that..." — `The problem is that ___.` **(Core 98)**
- *Ladder:* What would you change? → Why hasn't it changed? → Who would object? → What would it cost?
  → Have you raised it? → What happened, or why not?
- *Floor: Core 92.*

# Theme 7 · Habits and change

*The learner as evidence. Every question here has a factual answer about their own behaviour.*

**31. What's a habit you've actually managed to keep?**

*3秒: success is easier to talk about than failure, and this framing invites it.*
- Move A: "I've been doing it for..." — `I've been ___ing for ___.` **(Core 52)**
- Move B: "It stopped feeling like effort." — `It stopped ___ing.` **(Core 47)**
- *Ladder:* What is it? → How long? → How did you start? → What nearly stopped you? → What habits have
  you failed to keep? → What's different about the ones that stick?

**32. What time do you actually go to bed?**

*3秒: a number, and "actually" makes the honest answer available.*
- Move A: "I mean to go at eleven, but..." — `I mean to ___, but ___.` **(Core 56)**
- Move B: "It's got worse recently." — `It's got ___ recently.` **(Core 49)**
- *Ladder:* What time really? → What are you doing instead? → When did that start? → Does it matter? →
  Have you tried to fix it? → What actually helped?

**33. What's something you've changed your mind about?**

*3秒: specific and personal — and the change itself is the story.*
- Move A: "I used to think..." — `I used to think ___.` **(Core 75)**
- Move B: "What changed it was..." — `What changed it was ___.` **(Core 103)** `chunk`
- *Ladder:* What did you think before? → What do you think now? → What changed it — a person, an
  event? → Was it sudden or slow? → Have you told anyone? → What are you least likely to change your
  mind about?
- *Floor: Core 75.*

**34. What do you do differently from five years ago?**

*3秒: bounded comparison, and the answers come quickly.*
- Move A: "Five years ago I would never have..." — `Five years ago I would never have ___.` **(Core 71)**
- Move B: "Now I do it without thinking." — `Now I ___ without ___ing.` **(Core 12)**
- *Ladder:* One concrete difference → When did it change? → Did you decide, or did it just happen? →
  What's stayed exactly the same? → What will be different in five more? → Which change are you
  proudest of?
- *Floor: Core 71.*

**35. What's a rule you make for yourself?**

*3秒: people have these and enjoy explaining them.*
- Move A: "I never..." — `I never ___.` **(Core 17)**
- Move B: "I made that rule after..." — `I made that rule after ___.` **(Core 32)**
- *Ladder:* What's the rule? → How strict? → What happened to make it? → Have you broken it? → Do
  other people find it strange? → Is there a rule you should make and haven't?

# Theme 8 · Then and now

*Memory topics. High three-second compliance because recall of childhood is fast and vivid.*

**36. What were you like as a child?**

*3秒: everyone can start, and other people have told them the answer.*
- Move A: "Apparently I was..." — `Apparently I was ___.` **(Core 30)**
- Move B: "I don't remember it that way." — `I don't remember ___.` **(Core 27)**
- *Ladder:* What were you like? → Who says so? → Do you agree? → What's one specific memory? → How
  much of that is still true? → What would that child think of you now?

**37. What did you want to be?**

*3秒: instant, and the gap to now is the whole conversation.*
- Move A: "I wanted to be a..." — `I wanted to be ___.` **(Core 30)**
- Move B: "It's not that far from what I do, actually." — `It's not that far from ___.` **(Core 45)**
- *Ladder:* What did you want? → How old? → Where did the idea come from? → When did it change? →
  Do you ever think about it? → What would you tell that kid?

**38. What's a place from your childhood that's gone?**

*3秒: specific, physical, and the loss makes it memorable.*
- Move A: "There used to be a..." — `There used to be a ___.` **(Core 75)**
- Move B: "It's a convenience store now." — `It's ___ now.` **(Core 25)**
- *Ladder:* What was it? → What did you do there? → When did it go? → Did you notice at the time? →
  What's replaced it? → Does that bother you, or is that just how it works?
- *Floor: Core 75.*

**39. What did your family always do that you thought was normal?**

*3秒: the realisation is a story every adult has.*
- Move A: "We always used to..." — `We always used to ___.` **(Core 75)** `chunk`
- Move B: "I didn't realise until..." — `I didn't realise until ___.` **(Core 58)**
- *Ladder:* What was it? → When did you find out it wasn't normal? → How did you react? → Do you still
  do it? → What did other families do that seemed strange? → What will your family be known for?

**40. What's something you were sure about that turned out wrong?**

*3秒: a specific memory with a punchline.*
- Move A: "I was completely sure that..." — `I was completely sure that ___.` **(Core 30)**
- Move B: "It turned out I'd misunderstood the whole thing." — `It turned out ___.` **(Core 73)**
- *Ladder:* What did you believe? → How long? → How did you find out? → Who told you? → Did you argue?
  → Is there anything you're sure about now that you'd bet on?
- *Floor: Core 73.*

# Theme 9 · Choices

*Preference topics, anchored to real decisions the learner has actually made — not to abstractions.*

**41. Planner or improviser?**

*3秒: everyone knows which they are.*
- Move A: "I tend to plan everything." — `I tend to ___.` **(Core 12)**
- Move B: "It depends what it is." — `It depends ___.` **(Core 101)** `chunk`
- *Ladder:* Which are you? → Give me a recent example → When has it gone wrong? → Who do you travel
  with — same or opposite? → How does that go? → Has your answer changed with age?

**42. Would you rather be very good at one thing or okay at many?**

*3秒: a binary choice with an immediate gut answer.*
- Move A: "I'd rather be..." — `I'd rather ___ than ___.` **(Core 97)**
- Move B: "If anything, I've gone the other way." — `If anything, ___.` **(Core 116)** `chunk`
- *Ladder:* Which? → What are you actually good at? → What are you okay at? → Which has been more
  useful? → Do you know someone who's the opposite? → Would you change if you started again?
- *Floor: Core 92.*

**43. What's a decision you're glad you made?**

*3秒: people carry these and want to tell them.*
- Move A: "I decided to..., and..." — `I decided to ___, and ___.` **(Core 59)**
- Move B: "I should have done it sooner." — `I should have ___ sooner.` **(Core 71)**
- *Ladder:* What was it? → When? → What was the alternative? → Who advised you? Did you listen? →
  What would be different if you hadn't? → What decision is waiting now?
- *Floor: Core 71.*

**44. City or countryside — and where do you actually live?**

*3秒: the second half makes it factual and stops it becoming a debate.*
- Move A: "I live in the city, but I'd rather..." — `I live in ___, but I'd rather ___.` **(Core 97)**
- Move B: "In practice it's about..." — `In practice it's about ___.` **(Core 114)** `chunk`
- *Ladder:* Where do you live? → Is that a choice? → What would you gain by moving? → What would you
  lose? → Have you tried the other one? → What would have to be true for you to move?
- *Floor: Core 92.*

**45. What do you say no to?**

*3秒: a behaviour question with concrete answers.*
- Move A: "I've got better at saying no to..." — `I've got better at ___ing.` **(Core 49)**
- Move B: "I still can't say no to..." — `I still can't ___.` **(Core 20)**
- *Ladder:* What do you decline? → How do you actually word it? → What can't you refuse? → Who's good
  at it? → What happened last time you should have said no? → What would you like to refuse more?

# Theme 10 · Japan and elsewhere

*Comparison is natural for this learner and it is the conversation they will most often actually have
in English. Kept concrete — "what is Japanese culture" is an essay prompt; "what do visitors always
ask you" is not.*

**46. What do foreign visitors always ask you about?**

*3秒: it has literally happened to them.*
- Move A: "Everyone asks about..." — `Everyone asks about ___.` **(Core 13)**
- Move B: "I never know how to explain it." — `I never know how to ___.` **(Core 62)**
- *Ladder:* What do they ask? → What do you usually say? → What's hard to explain? → What do they get
  wrong before they come? → What do they notice that you'd never thought about? → What should they
  ask instead?

**47. What surprised you most outside Japan — or what do you expect would?**

*3秒: the alternative clause means this works for people who have never left.*
- Move A: "The thing that surprised me was..." — `The thing that surprised me was ___.` **(Core 103)** `chunk`
- Move B: "I'd assumed it would be..." — `I'd assumed it would be ___.` **(Core 73)**
- *Ladder:* What was it? → What had you expected? → Where did the expectation come from? → Did you
  adjust or stay uncomfortable? → What did you miss most? → What did you not miss at all?
- *Floor: Core 73.*

**48. What works better somewhere else?**

*3秒: specific and concrete — trains, queues, service, rubbish.*
- Move A: "They do it completely differently there." — `They ___ differently ___.` **(Core 15)**
- Move B: "To be fair, ours has its advantages." — `To be fair, ___.` **(Core 93)**
- *Ladder:* One concrete example → How does it work there? → Why does it work? → Would it work here? →
  What would have to change? → What works better here that people don't notice?
- *Floor: Core 92.*

**49. What's hard to explain about where you're from?**

*3秒: not "Japan" — their actual town, which they know in detail.*
- Move A: "It's not really a city, more of a..." — `It's not so much a ___ as a ___.` **(Core 89)**
- Move B: "You'd have to see it." — `You'd have to ___.` **(Core 66)**
- *Ladder:* Where are you from? → What's it actually like? → What do people assume? → What's the one
  thing you'd show a visitor? → Would you move back? → What would you miss if it changed?
- *Floor: Core 89.*

**50. Has learning English changed how you see anything?**

*3秒: they are doing it right now, so evidence is immediate — and it's the one abstract question the
track earns, because the whole course is the experience it refers to.*
- Move A: "I've noticed that..." — `I've noticed that ___.` **(Core 49)**
- Move B: "On balance, it's made me..." — `On balance, ___.` **(Core 117)**
- *Ladder:* What have you noticed? → About English, or about Japanese? → Has it changed how you say
  things in Japanese? → Has it changed who you talk to? → What's been hardest? → Would you start again
  knowing that?
- *Floor: Core 117.* **The closing topic of the track** — deliberately the only fully reflective one,
  and it works because the learner has fifty sessions of evidence.

## Adding a topic

Run it through the four selection rules first. In particular, write the topic title and then answer
it yourself, out loud, in your own language, and time it. If the first sentence takes longer than
three seconds, the topic is an essay prompt — rewrite it toward an experience or drop it.

Then write the **B2–C1 version first**, unconstrained. Derive the B1 version by simplifying the
opening passage, and change only the questions that genuinely block. Do not shorten the thinking.

Every topic needs its own ladder. A generic ladder means the tutor improvises the session, and the
ladder is where the session's value actually lives.
