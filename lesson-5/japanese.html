TODAY'S PATTERNS

PATTERN A — [noun]をwo [verb]ますmasu   (I do / Do you / I don't)

Three endings, one pattern:

〜ますmasu   → I do it   (positive)
〜ますmasuかka   → Do you…?   (question)
〜ませんmasen   → I don't   (negative)
• わたしwatashiはwaごはんgohanをwoたべますtabemasu。
I eat rice.
• ほんhonをwoよみますyomimasuかka？
Do you read books?
  → はいhai、よみますyomimasu。／ いいえiie、よみませんyomimasen。
Yes, I do. / No, I don't.
• テレビterebiをwoみませんmimasen。
I don't watch TV.

PATTERN B — [noun]をwo [verb]ませんかmasen ka？   (Shall we…? / Would you like…?)

Same 〜ません ending, but it's an INVITATION, not a "no".

• コーヒーkōhīをwoのみませんかnomimasen ka？
Shall we drink coffee? / Would you like some coffee?
• えいがeigaをwoみませんかmimasen ka？
Shall we watch a movie?
REMEMBER
をwo → the thing you act on (rice, coffee…)
〜ますmasu / 〜ますmasuかka / 〜ませんmasen   = Pattern A
〜ませんかmasen ka   = Pattern B (invite)
