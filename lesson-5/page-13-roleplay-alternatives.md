# Page 13 Roleplay — Alternative Designs

Problems with the current page:
- Three overlapping instruction blocks (SCENARIO + GOAL + やること) say the same thing
- Bilingual procedural text doubles reading time for tutor & student
- HINTS box re-teaches patterns already drilled on pages 3–5
- No visual anchor — it's all prose
- Roles aren't instantly obvious (tutor has to infer they're "the friend")

Goal for every alternative below: **tutor and student both know their role and first move within 5 seconds of landing on the page.**

---

## OPTION 1 — Menu-driven (visual anchor, near-zero instructions)

Replace the entire setup with a cafe menu graphic. The menu IS the activity.

```
+-------------------------------------------------------------------------+
|                                                                         |
|  ROLEPLAY — AT THE CAFE                                                 |
|                                                                         |
|  TUTOR = ウェイター (waiter)    STUDENT = おきゃくさん (customer)         |
|                                                                         |
|  ┌─── ☕ CAFE MENU / メニュー ─────────────────────┐                      |
|  │                                                 │                      |
|  │   DRINKS / のみもの                              │                      |
|  │     コーヒー    ¥400                             │                      |
|  │     おちゃ      ¥300                             │                      |
|  │     みず        ¥100                             │                      |
|  │                                                 │                      |
|  │   FOOD / たべもの                                │                      |
|  │     ごはん      ¥600                             │                      |
|  │     パン        ¥300                             │                      |
|  │     ケーキ      ¥400                             │                      |
|  │                                                 │                      |
|  └─────────────────────────────────────────────────┘                      |
|                                                                         |
|  TUTOR opens:  「いらっしゃいませ！なにを のみますか？」                    |
|                                                                         |
|  ✨ Bonus: invite the tutor with 〜ませんか？                             |
|      (e.g. いっしょに ケーキを たべませんか？)                              |
|                                                                         |
+-------------------------------------------------------------------------+
```

**Why it works:** menu = shared focal point. Tutor's opening line is pre-written so they don't stall. Student orders by pointing + speaking. The 〜ませんか prompt is one line, not a paragraph.

**Tradeoff:** less student agency in choosing scenario flow. Best for students who freeze without structure.

---

## OPTION 2 — Role cards (two tiny cards, nothing else)

Split the page into two role cards. Each person reads ONLY their own card.

```
+-------------------------------------------------------------------------+
|                                                                         |
|  ROLEPLAY — AT THE CAFE                                                 |
|                                                                         |
|  ┌─── 👤 TUTOR (waiter) ────────┐ ┌─── 🧑 STUDENT (customer) ──────┐    |
|  │                               │ │                                 │    |
|  │  Greet the customer.          │ │  ① Order a drink               │    |
|  │  Ask:                         │ │  ② Order food                  │    |
|  │    なにを のみますか？         │ │  ③ Invite tutor: 〜ませんか？   │    |
|  │    なにを たべますか？         │ │                                 │    |
|  │                               │ │  Words: コーヒー・おちゃ・みず  │    |
|  │  React naturally to           │ │         ごはん・パン・ケーキ    │    |
|  │  invitations.                 │ │                                 │    |
|  │                               │ │                                 │    |
|  └───────────────────────────────┘ └─────────────────────────────────┘    |
|                                                                         |
+-------------------------------------------------------------------------+
```

**Why it works:** each person reads ~20 words, not 100. Role is labeled top-left of the card. Student has a 3-step checklist — unambiguous "what do I do first."

**Tradeoff:** requires the tutor to keep their card private-ish, or students may read both and lose the surprise.

---

## OPTION 3 — Mission checklist (gamified, minimal prose)

Ditch scenario prose entirely. Show three missions as checkboxes. The student's job is to complete all three in a cafe conversation.

```
+-------------------------------------------------------------------------+
|                                                                         |
|  ROLEPLAY — AT THE CAFE ☕                                              |
|                                                                         |
|  Tutor = waiter. Student = complete 3 missions!                         |
|                                                                         |
|  ┌──────────────────────────────────────────────────────────┐           |
|  │                                                           │           |
|  │   ☐ MISSION 1:  Order a drink        (〜を のみます)       │           |
|  │                                                           │           |
|  │   ☐ MISSION 2:  Order food           (〜を たべます)       │           |
|  │                                                           │           |
|  │   ☐ MISSION 3:  Invite the tutor!    (〜を 〜ませんか？)   │           |
|  │                                                           │           |
|  └──────────────────────────────────────────────────────────┘           |
|                                                                         |
|  Words:  コーヒー・おちゃ・みず・ごはん・パン・ケーキ                    |
|                                                                         |
|  Tutor opens:  「いらっしゃいませ〜」                                      |
|                                                                         |
+-------------------------------------------------------------------------+
```

**Why it works:** the checkbox format is self-explanatory — student sees "3 things to do" instantly. Clicking / ticking the boxes could be interactive for web version. No scenario prose at all; the missions ARE the scenario.

**Tradeoff:** less immersive than a menu or role-card setup. Feels more like a drill than a roleplay.

---

## OPTION 4 — Dialogue skeleton (lowest-friction, highest scaffolding)

Pre-fill a dialogue skeleton with 3 blanks. Student fills in and speaks. This is Page 11 (Memory Conversation) pattern but used for novel production.

```
+-------------------------------------------------------------------------+
|                                                                         |
|  ROLEPLAY — AT THE CAFE                                                 |
|                                                                         |
|  Fill the blanks with YOUR choice, then act it out with the tutor.      |
|                                                                         |
|  WAITER:    いらっしゃいませ！なにを のみますか？                         |
|  YOU:       わたしは _______ を のみます。                                |
|                                                                         |
|  WAITER:    なにを たべますか？                                           |
|  YOU:       _______ を たべます。                                         |
|             そして、いっしょに _______ を たべませんか？                   |
|                                                                         |
|  WAITER:    はい、いいですね！                                            |
|                                                                         |
|  Word bank:  コーヒー・おちゃ・みず・ごはん・パン・ケーキ・すし           |
|                                                                         |
+-------------------------------------------------------------------------+
```

**Why it works:** zero ambiguity about flow. Student writes three words, then performs. Both people see the whole dialogue at once so neither wonders "what's next?". Fits in 2 minutes easily.

**Tradeoff:** feels closer to a fill-in than a roleplay. Good for nervous beginners, less good for students who want freedom. You already have a similar activity on Page 14 (Travel in Japan), so this option risks redundancy.

---

## Recommendation

**Option 2 (Role cards) or Option 3 (Mission checklist)** best match the complaint. Both kill the instruction prose, make roles instantly readable, and give the student a concrete first move without over-scaffolding.

- **Pick Option 2** if you want the tutor to stay flexible (improvise reactions) and the student to drive.
- **Pick Option 3** if you want maximum clarity / minimum ambiguity — great for first-time students.

Option 1 (Menu) is the most visually appealing but takes more page real estate. Option 4 (Skeleton) overlaps too much with Page 14 already.
