Is There...? — Lighter Class Version

This version reduces burnout by using:

  • multiple choice
  • one-blank writing
  • image-supported tasks
  • choice-first speaking

THINGS

PATTERN: [place]に [thing]が あります。

1. Read Together

• へやに テレビが あります。
• きょうしつに とけいが あります。
• いえに ほんが あります。

2. One-Blank Fill

• へやに テレビが（あります / います）。
• きょうしつに とけいが（あります / います）。
• いえ（に / が）ほんが あります。
• カフェに（ペン / ねこ）が あります。

3. Guided Writing

There is a phone in the room. There is a key at home. There is a notebook at the cafe.

PATTERN DRILL B LITE: いますimasu

PEOPLE / ANIMALS

PATTERN: [place]に [person/animal]が います。

1. Read Together

• きょうしつに せんせいが います。
• へやに ねこが います。
• いえに いぬが います。

2. One-Blank Fill

• きょうしつに せんせいが（います / あります）。
• へやに（ねこ / テレビ）が います。
• カフェ（に / が）ともだちが います。
• いえに いぬが（います / あります）。

3. Guided Writing

There is a teacher in the room. There is a dog in the park. There is a friend at home.
